# Dokumen projek Baba Chat

Folder ini untuk **kumpulan** (rujukan, semakan dan laporan). Aplikasi tidak membaca fail dalam folder ini.

| Fail | Isi |
|---|---|
| `maklumat-projek.md` | Nama kumpulan, ahli, enjin yang digunakan, nombor bantuan |
| `panduan-reka-bentuk.md` | Warna, fon, bentuk butang, latar setiap skrin, mod malam, muzik, suara Baba, bunyi butang |
| `senarai-aset.md` | Setiap fail dalam `assets/` dan skrin yang menggunakannya |
| `pratonton-aset.png` | Gambar semua aset dalam satu halaman |
| `Baba-Bank-Soalan.xlsx` | Semua soal jawab untuk disemak kumpulan (lajur kuning) |
