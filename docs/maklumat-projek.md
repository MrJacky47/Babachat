# Maklumat projek

**Baba Chat**: aplikasi pendidikan keselamatan online untuk kanak-kanak, khususnya pencegahan grooming dalam talian.
Maskot: **Baba**, seekor meerkat 3D yang sentiasa berjaga-jaga untuk kawan-kawannya.

Projek Kerja Sosial, Universiti Sultan Zainal Abidin (UniSZA).

## Dibina dengan

| Alat | Kegunaan |
|---|---|
| three.js · WebGL | Memaparkan dan menggerakkan Baba 3D |
| Python · NumPy · SciPy | Memodel, membentuk dan menjana animasi Baba 3D; menjana muzik |
| Web Audio API | Bunyi butang dan dialog |
| HTML, CSS & JavaScript | Antara muka aplikasi |
| Baloo 2 & Lexend (Google Fonts) | Fon |
